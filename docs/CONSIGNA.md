# Requisitos de referencia — TP2 Frontend II

Resumen de las siete capturas de la consigna compartidas en esta conversación. Ante dudas, prevalece la consigna original.

## Objetivo y alcance acordado

Crear una aplicación dinámica con React + Vite y herramientas de IA como apoyo, datos persistentes en Cloud Firestore y publicación en Vercel. La propuesta debe resolver una necesidad concreta y tener un flujo de interacción completo. Trabajo individual o en grupos de hasta dos integrantes.

**¿Qué cocino?** ayuda a personas que cocinan en casa a elegir una receta a partir de un ingrediente, guardar favoritas y gestionar los ingredientes que les faltan. La API de recetas es un complemento; no reemplaza Firestore.

## Requisitos obligatorios

- React + Vite: componentes, eventos y estado.
- Firestore: consultar, agregar, modificar y eliminar registros.
- Persistencia al recargar. Un array o localStorage no cumplen este requisito.
- GitHub: código fuente e instrucciones de ejecución.
- Vercel: URL pública funcional.
- Validación básica, estados de carga, mensajes de éxito y error; uso en computadora y celular.
- Reglas de permisos que no permitan lectura y escritura irrestrictas.
- `.env.example`, archivo de reglas y README incluidos; `.env`, `node_modules` y `dist` excluidos.

## Proceso

- Al menos tres versiones reales: inicial funcional, mejoras, final.
- Registrar qué cambia, por qué, cómo se verificó y qué dificultades aparecieron.
- Acompañar con capturas u otras evidencias reales.

- Revisar y probar el código generado con IA. Poder explicar conexión y operaciones sobre datos.
- Justificar el diseño y refinarlo, no entregar solamente el primer resultado de IA.
